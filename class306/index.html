Field Manual

This page is built for the middle of a run

305 teaches the Fractal system. This page is the quick-reference manual you open when your party is already standing in the Observatory or inside an encounter.

Search the Fractal name, open the guide, and focus on the section you're currently running.

How to Use It

Prepare → Execute → Recover

Prepare

Check the useful tools

Each guide lists useful utility such as Stability, cleanse, crowd control, projectile defense, or movement.

These are encounter tools, not required professions.

Execute

Open only what you need

Encounter phases are separated into expandable sections so you don't have to scroll through an entire guide.

Recover

Check common mistakes

If the group wipes or something suddenly goes wrong, check the mistakes panel first.

Universal Field Calls

Short words, quick reactions

These calls show up across Fractals and other organized group content.

BREAK

Use crowd control on the active blue Defiance Bar.

SPREAD

Create space so targeted attacks don't overlap.

STACK

Group tightly for shared healing, boons, defense, or split damage.

DROP OUT

Carry a targeted field or bomb away from the party before it lands.

Mobile Use

Search, scan, close

Veteran Field Note

Don't read the whole guide during combat

If your group is waiting at a boss, look for the phase you're about to do.

The manual is a pocket card, not a textbook.
