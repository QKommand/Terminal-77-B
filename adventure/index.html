Account Safety

Know what you're connecting

Some community tools can use a Guild Wars 2 API key to read selected information from your account.

Generate API keys through your official ArenaNet account page and only give a tool the permissions it actually needs.

Never give a community website your ArenaNet account password.

Veteran Field Note

More information isn't always more useful

A new player can open a build site, wiki, account tracker, market calculator, achievement guide, and lore archive at the same time and somehow know less than when they started.

Start with the question you're trying to answer. Then open the tool built for that question.
